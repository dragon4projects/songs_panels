The next independent art task is to extend the four **mergeable** TEEA 003 room families to their authored R2/R3 widths:

- Music R2

Do **not** redraw or revise the finished R1 variants while the owner reviews the Mac build.

## Visual continuity

Use the completed 003 R1 rooms as the visual DNA for each family:
- same materials, lighting logic, architectural language and furniture family;
- R2/R3 must read as a genuinely larger shared room, **not** as R1 copied two/three times;
- keep a clear back / mid-depth / physical-front hierarchy;
- preserve the current cutaway-shell calibration and public walking aisle;
- no decorative object may block the aisle or a room-to-room doorway.

All room PNG are still authored against the established Dragon House layer calibration.

## Layer contract

For every variant deliver only the layers physically needed:
- `backdrop`
- `back_decor`
- `furniture_back`
- `foreground` only where actual furniture/body occlusion requires it.

Keep:
- exact 1536 x 1024;
- RGBA8;
- transparent alpha where appropriate;
- `approved:false`;
- SHA-256 for every production PNG.

Do not add foreground merely for visual richness.

## Foreground metadata — required this time

For every foreground layer include an explicit runtime physical cut plane:

`physical_z: <Godot-local physical Z of the furniture edge represented by the foreground fragment>`

Also record:
- source furniture ID;
- Blender/Godot measurement used;
- whether the cut plane is front edge, seat edge or another measured plane.

This prevents the integrator from having to reconstruct the depth from geometry afterward.

## Width-aware physical stations

R2/R3 station data must be authored by **module index**, because Dragon House now resolves furniture contracts as:

`<room_type>:R<width>:<module_index>`

Examples:
- `music:R2:0`
- `music:R2:1`
- `cinema:R3:0`
- `cinema:R3:1`
- `cinema:R3:2`

For every physical station provide:
- stable station ID;
- furniture ID;
- module index;
- module-local x;
- module-local z;
- kind;
- pose hint;
- approach_local_z;
- occupancy_capacity = 1;
- collision footprint of the source furniture.

Also list collision-only furniture with footprints.

Do not infer station positions from the finished PNG. Measure them from the authored geometry.

## Functional targets

These are room functions, not mandatory object counts:

### Music
Must visibly support listening / music-room life at larger widths.
R2/R3 should gain useful physical listening space rather than only empty decorative width.

### Cinema
Must support several viewers without forcing sprites to overlap.
Seat positions must correspond to real measured seat centres.
Foreground sofa/chair fragments must use explicit `physical_z`.

### Artifact
Must provide several distinct standing-view targets with clear sight lines.
Viewing stations stay outside display/cabinet collision volumes.

### Workshop
Must provide several real work positions.
A work station may be at a stool/bench/work surface only if the body can approach it without crossing another furniture footprint.

The runtime per logical cell currently allows:
- Music: 6 total stations,
- Cinema: 8,
- Artifact: 6,
- Workshop: 4.

Artist-authored furniture stations do not need to fill the entire capacity; remaining capacity may use safe standing positions generated by runtime. Prefer fewer physically true stations over invented seats.
